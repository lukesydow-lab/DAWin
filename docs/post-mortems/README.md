# Sprint Post-Mortems

**Status: Current**
**Last updated:** 2026-05-31
**Owner:** Writer Agent (PM review required before publish)

Sprint post-mortems are the institutional memory of DAWin's development. They exist so that:

1. Humans joining the project can understand not just what was built, but why decisions were made and what was learned.
2. The team can improve its process over time — not by assigning blame, but by being honest about what happened.
3. Nothing is lost when context windows end or team composition changes.
