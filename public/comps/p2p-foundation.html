Peer-to-Peer Communications — Round 1: Foundation

The always-visible foundation. Talkback button, voice filter selector, and peer presence rail in the transport bar. Push-to-talk via T. Designed to obey "easy to use, easy to find, not in the way."
Where everything lives. The talkback button sits in the transport bar — always visible, one key press away, but only ~46px wide. Peer presence is a horizontal rail on the right side of the transport bar — compact pills that pulse with each speaker's voice. The voice filter selector is a small chevron tucked next to the talkback button, opening a popover when needed. Total horizontal footprint added to the transport bar: ~280px on a 1280px viewport. Less than the existing collaborator avatar stack.

1. Talkback button

Round LED dome on a brushed-metal housing. Off = dark red recessed dome. Live = bright red core with halo glow + subtle pulse animation. Studio talkback convention.

Hold T or click + hold the button to talk. Release to mute. The button face shows T as the keyboard label, so the shortcut is taught visually on the hardware itself.

"ON AIR" label appears in the hint bar below the transport when actively transmitting — secondary confirmation that doesn't intrude on focus.

2. Voice filter selector

A small chevron pill (∿ Clean ▾) next to the talkback. Click to open the filter popover — 8 presets including Clean, Vocoder, Robot, Telephone, Megaphone, Pitch ±1 oct, and "God Mode" (producer reverb for talking down to the band from on high).

Selected filter is shown in the pill label so the user can see at a glance what they sound like to others. Try it — click the pill.

3. Peer presence rail

Compact horizontal pills, one per active collaborator (3–5 typical). Each pill = owner color tint + initial avatar + display name.

Audio-reactive: when a peer is speaking, their pill gets a glowing ring that intensifies with their voice level. Watch Anna and Miguel in the demo — they cycle through speaking states with simulated audio levels.

Scales: at 6+ peers, the rail collapses to "+N more" overflow. Clicking opens the gallery view (Round 3).

Push-to-talk physics

Key choice: T. Reasoning:

• Mnemonic — T = Talk. The button itself displays the letter, so the shortcut teaches itself
• Doesn't collide with Space (play/pause), V (Select), or C (Cut)
• Single-key hold-to-talk — no awkward modifier combos
• Skipped in text inputs (same protection Space gets)
• Intentional friction during recording — release to mute

Click + hold the button works identically — mouse and keyboard paths produce the same behavior. See docs/specs/keyboard-shortcuts.md for the full system shortcut map.

Mic state indicator

A small dot at the bottom-corner of each peer's avatar:

• ● Green = mic enabled (the peer CAN talk if they hold their key)
• ● Grey = mic muted at hardware level
• Glowing owner-color ring = currently transmitting

This separates "mic available" from "actively talking" — both matter in a studio context.

Footprint

The whole comms bay (talkback + filter selector) adds ~120px to the transport bar. The peer presence rail floats right with ~26px per peer.

At 5 peers, the total comms footprint is roughly 250px. The transport bar is ~1280px wide, so 20% of the bar is comms. Nothing dropped from the existing layout. Everything else is the same.

At 20+ peers, the rail collapses to overflow — never spills.

Round 2 — Fun layer

Soundboard (4×4 hot pad grid, user-loadable + built-in classics), floating reactions across the canvas, avatar effects (spotlight on the active speaker).

All on-demand. Soundboard summons via icon in transport. Reactions trigger from emoji picker.

Round 3 — Expanded views

Gallery view (FaceTime-style grid that slides up from below). Producer Interrupt mode (full-screen 1:1 video that intentionally breaks "not in the way").

Both summoned on-demand, both dismissible with one keystroke.

Round 4 — System integration

Music-context behaviors: voice ducks during loud playback, reactions snap to bar grid, spatial audio panning matches mixer position, comms heartbeat ties to the startup heartbeat.

This is where the "feels like part of the studio gear" promise is delivered.
