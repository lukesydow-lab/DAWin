1. Soundboard (hardware-style)

Floating panel, draggable header. 4×4 MPC-style backlit rubber pads. Each pad shows the sound name + keyboard shortcut. Press a pad → it depresses, the LED flashes in your owner color, a ripple radiates outward, and the sound broadcasts to everyone in the session.

Keyboard layout mirrors a hardware sample-pad controller (Splice, Ableton Push, NI Maschine): bottom-left 4×4 keyboard region — 1234 QWER ASDF ZXCV. Active only when the soundboard is open (modal scope), so V/C don't conflict with tool shortcuts.

Right-click any pad to open the context menu — play, replace, rename, set color, adjust volume, change playback mode, or remove.

2. Reactions (emoji)

Click the 😀 button or press ⌘⇧E to open the reaction picker. Click any emoji → it floats from your peer pill upward across the arranger canvas, owner-color ring around it, fading after ~3 seconds.

Music-context magic: when playback is active, reactions snap their arrival point to the bar grid. A high-five during the chorus actually lands on a downbeat. Subtle, but reinforces "this is part of the studio."

Reactions are non-modal — emit one and keep working. Multiple peers can react simultaneously; each gets their own color-tinted ring so you can see who said what.

3. Avatar effects (automatic)

Building on Round 1's audio-reactive pulses, Round 2 adds spotlight when a peer holds the floor for >1.5 sec:

• The active speaker's pill scales 1.08× with an extended owner-color glow halo
• All other peer pills dim to 55% brightness / 70% saturation for the duration
• When the speaker stops, all pills return to baseline over 240ms

Effect: the active speaker visually steps forward, others step back. Watch Anna or Miguel in the demo when they're speaking longer than usual.

Placement decisions

Soundboard launch button lives in the comms bay next to the talkback. The "▦" icon and "SB" label make it findable. Active state has owner-color glow + inner ring.

Emoji button sits to the right of the soundboard button. Same hardware aesthetic. The picker drops down from the button position.

Soundboard panel is initially anchored top-right, draggable by the header. The user can move it wherever's convenient. Closes via × or Esc. Open the soundboard and drag it — try it now.

Keyboard shortcuts added in Round 2

Panel triggers (global):
• ⌘⇧S — Open / close soundboard
• ⌘⇧E — Open / close emoji picker
• Esc — Close whatever's open

Soundboard pads (when open):
Bottom-left 4×4 keyboard region — 1234 / QWER / ASDF / ZXCV. Standard production-controller layout.

Note: Z, X, C, V conflict with future-reserved tool keys (Zoom, Trim, Cut, Select) at the global level, but the soundboard captures focus when open — these conflict-by-design and resolve to soundboard pads while in modal scope. All documented in docs/specs/keyboard-shortcuts.md.

What this round honors

Easy to find — both new buttons live next to the talkback button. Same comms bay, same hardware aesthetic.

Easy to use — every interaction has a keyboard shortcut and a clickable visual. Pads light up. Emojis float. Spotlight is automatic.

Not in the way — soundboard only appears when summoned; emoji picker only opens when clicked; reactions auto-fade; avatar spotlight is subtle, not modal. The arranger is fully visible behind everything except the soundboard, which is repositionable.

Loading flow — how custom sounds get onto pads

Entry points (three paths)

1. Click "+ Load" pad → soundboard transforms in place from grid view to load view. Target pad is whatever empty slot you clicked.

2. Right-click any existing pad → "Replace sound…" — same load view, but the target is the pad you right-clicked.

3. Drag a file from Finder/Explorer directly onto any pad — skip the load view entirely. The pad you drop on gets the sound. Watch for the purple highlight as you hover.

Try it — open the soundboard, click the "+ Load" pad in the bottom-right corner.

Load view contents

The grid is replaced (same 320px panel, same header) with three sections:

1. Drop zone — Big dashed area at the top. Drop a file or click to browse. Supported: WAV, MP3, OGG, AIFF. Max 5 MB.

2. From session — Horizontal scroll of session clips. Each clip shows a mini-waveform tinted in its owner color. Click a clip to assign it to the pad. This is the DAWin-magic move: the same clips you're arranging are one click from becoming a soundboard hit.

3. Library — Categorized presets (Drum kits, Voice tags, Stings, Impacts). Each opens a sub-browser (not built in this prototype) for deeper selection.

Loading animation

When a file/clip is selected:

0–50ms: Load view dismisses, pad becomes the target
50–1250ms: Pad enters loading state — soft owner-color glow pulse + a horizontal scan line crosses left-to-right (simulates waveform analysis)
1250–1900ms: Pad pulses with white ring + scales briefly (confirmation), then settles into its new loaded state

The user sees their pad transform IN PLACE. No spinner overlay, no modal. The pad itself shows the loading state — which keeps the user's eye exactly where they need to look to confirm the load.

Right-click context menu

Right-click any pad (with a sound loaded) to open a small floating menu:

• Play — preview the sound (with keyboard shortcut shown)
• Replace sound… — opens the load view for this pad
• Rename… — inline rename
• Set color… — override the owner color for this pad
• Adjust volume… — per-pad volume
• Playback mode… — one-shot / loop / choke group
• Remove sound — pad returns to empty "+ Load" state

Standard right-click affordance, closes on outside click or Esc.

Drag from Finder/Explorer

When you drag an audio file onto the soundboard window:

• Soundboard outline glows purple — indicates the panel is a valid drop target
• The pad you're hovering over highlights — purple background + bright border, so you can see which slot will receive the sound
• Drop — that pad gets the sound. Same loading animation as the in-app flow.

This is the power-user path. No clicks, just drag and drop. Files keep their names by default (editable via right-click → Rename).

Errors (not in this prototype but specced)

File too large (>5 MB): Drop zone shakes briefly, shows "File over 5MB — pick a shorter clip" in danger color, returns to default state after 3s.

Unsupported format: "Use .wav, .mp3, .ogg, or .aiff" inline message under the drop zone.

Decode failed: Pad shows an error state (small ⚠ icon) for 2s, then returns to "+ Load".

All errors are non-modal — they appear inline in the load view or on the pad face itself. No interruption to the rest of the session.
