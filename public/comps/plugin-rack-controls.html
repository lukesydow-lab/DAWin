Four rack-unit types in one cabinet: standard 4-knob (Compressor), EQ with draggable crossovers, One Knob hero (Maximizer), and a third-party plugin with custom-mapped controls + pages + GUI launcher.
The rack IS the interface. 140px tall units fit 4 working knobs with descriptors. Native plugins use the rack only — there's no "full GUI" because the rack is the whole plugin. Third-party plugins expose 4 manufacturer-default controls (or custom-mapped ones) on the rack and reveal their full GUI on double-click. Right-click any knob → Map Control for the parameter-learn workflow.

The four rack types

1. EQ — 3 gain knobs, draggable crossover frequencies along the bottom (drag the amber labels to shift Low/Mid and Mid/High boundaries).

2. Standard (Compressor) — 4 knobs in a row. Same layout for Comp, Reverb, Delay, Exciter.

3. Hero (Maximizer) — One big knob (76px), gain-reduction meter on the right, dry/wet slider below. OUT trim removed — dry/wet replaces it (parallel-comp move).

4. Third-party — 4 mapped controls + page dots + GUI launcher (↗). Knobs show the bound parameter name as the label.

Map Control workflow

Right-click any knob on the third-party rack to open the menu. Choose "Map Control…" — the plugin window opens, the rack knob pulses owner color (learn mode), and you wiggle any parameter in the plugin GUI. First parameter that fires its event gets bound to the rack knob. Descriptor updates instantly.

Right-click the INPUT knob on the Vintage 1176 to try it.

Audio-reactive hero LED ring

The big LOUD knob's arc isn't just a value indicator — it pulses brighter with simulated gain reduction. The arc color shifts green → amber → red at 60% and 85% of value, giving immediate "you're slamming it" feedback.

Settings toggle (future spec): Settings → Visual feedback → Audio-reactive plugin glow

Drag-to-reorder (at 140px)

Bigger units = easier drag targets. Grab any rack body (not a knob) and drag — purple insertion line appears between racks at the drop position. Release to commit.

The chain is scrollable when there are more than ~5 racks — total height stays manageable.

Knob component — extended, not duplicated

The same Knob component renders at 36px (standard) and 76px (hero). Two new opt-in props:

• strokeMul — multiplies arc + pointer thickness (defaults to 1.0)
• zones — optional [green→amber threshold, amber→red threshold] for hot-zone color shift

Design system net change: +0 components, +2 props on existing Knob.
